## ۲. خلاصه بازطراحی صفحه محصول

- **Hero:** تصویر اصلی ۴:۵/۱:۱ با پس‌زمینه استودیویی radial، زوم ۱.۷× دنبال‌کننده نشانگر (desktop)، ریل بندانگشتی با حالت فعال، دکمه «تمام‌صفحه» و شمارنده شیشه‌ای (glassmorphism) — همه‌چیز transform/opacity (بدون layout thrash).
- **لایت‌باکس:** تمام‌صفحه با backdrop-blur، سوایپ لمسی (drag x با آستانه ۷۰px)، جهت‌ها/Esc، بندانگشتی‌ها، برگرداندن فوکوس.
- **اطلاعات:** تایپوگرافی درشت‌تر (h1 تا 38px)، فضایremium، ردیف امتیاز+SKU، چیپ‌های بسته‌بندی/خاستگاه، قیمت در کارت سایه‌دار.
- **خرید:** QtyPicker + دکمه اصلی پرشده؛ «خرود فوری» با آیکون Zap؛ «استعلام قیمت عمده» خط‌چین طلایی → پرتال B2B؛ سه‌گانه علاقه‌مندی/نشانک/اشتراک (Web Share API با fallback کپی).
- **جزئیات:** ۹ بخش آکاردئونی (توضیحات/مشخصات/ترکیبات/ارزش غذایی/نگهداری/ارسال/خرید عمده/FAQ/نظرات) با انیمیشن grid-rows و آیکون‌های برند.
- **بخش‌های هوشمند:** مشابه‌ها + اغلب با هم + پیشنهاد هلسا (محبوب‌های همان دسته) + اخیراً مشاهده‌شده + مقالات مرتبط مجله.
- **موبایل:** نوار خرید چسبان پایین با قیمت زنده.

## ۳. بهبودهای کارت محصول

سایه‌های premium (`shadow-soft` → `shadow-lift` با هاور)، گوشه‌های ۱.۴rem، هاور ۶px، دکمه «افزودن» شناور روی تصویر (فقط pointer: hover/focus-visible — موبایل دست‌نخورده)، نشان‌های شیشه‌ای «طبیعی» (Leaf) و «عمده» (Building2)، درصد تخفیف صریح، قیمت تمیز tabular-nums، تصویر با AVIF/WebP srcset و اندازه‌های vw-آگاه.

## ۴. بهبودهای سئو

- **Title/Description یکتا و داینامیک** در همه صفحات کلیدی؛ مصرف `seoTitle`/`seoDescription` واقعی DB (محصول و دسته).
- **Canonical** همه صفحات (دسته‌ها به `/products` — بدون محتوای تکراری پارامتری).
- **OG کامل** (title/description/image/type/url/site_name/locale) + **Twitter Card** (`summary_large_image`) در محصول/دسته/بلاگ/هوم.
- **تصویر OG برند** ۱۲۰×۶۳۰ با متن فارسی شکل‌گرفته صحیح (arabic-reshaper + bidi).
- ۵ sitemap پویا (با image extension) + robots با قانون AI — از ۱.۵.۰ پابرجا و بازتأیید شد.
- لینک‌سازی داخلی جدید: محصول ↔ مقالات مجله (تطبیق موضوعی)، مجموعه‌ها ↔ سینی/هدیه/عمده، breadcrumb همه‌جا.

## ۵. متاتگ‌های اعمال‌شده

`charSet` (خودکار Next)، viewport (viewport-fit=cover)، description یکتا، canonical، OG کامل، Twitter Card، `theme-color` دو-تم، `formatDetection`، `apple-touch-icon` + `apple-mobile-web-app-capable`، favicon.ico/16/32/48، PWA icons (192/512/maskable)، `verification.google` از env (`NEXT_PUBLIC_GSC_VERIFICATION`)، robots index/follow. **بدون meta keywords** (گوگل نادیده می‌گیرد).

## ۷. بهبودهای GEO (بهینه‌سازی موتورهای مولد)

- **بلوک پاسخ** ۲-۳ جمله‌ای زیر H1 هر محصول: موجودی قیمت+وزن+خاستگاه+ارسال — مستقیم قابل استناد توسط ChatGPT/Perplexity.
- **FAQ ماشین‌خوان** (FAQPage) روی هر صفحه محصول: قیمت، زمان ارسال، نگهداری، طبیعی‌بودن، خرید عمده.
- **واقعیت‌های ساخت‌یافته:** مشخصات جدول‌شده (SKU/وزن/برند/خاستگاه) + nutrition جدولی + موجودی واقعی.
- robots.txt: ۱۱ خزنده AI صریحاً مجاز روی محتوای عمومی (از ۱.۵.۰، بازتأیید شد).
- **نام‌فایل‌های توصیفی** تصاویر (برای grounding تصویری مدل‌ها): `mazafati-dates.avif` نه `17302469.jpg`.

## ۸. بهبودهای AEO

- پاسخ ۴۰-۶۰ کلمه‌ای در ابتدای صفحه؛ هدینگ‌های معنایی (h1→h2→h3 بدون پرش)؛ آکاردئون‌های با متن کامل قابل خزش (نه lazy-loaded).
- سرچ‌اکشن سایت (sitelinks searchbox)؛ schema کامل؛ متن alt توصیفی فارسی همه تصاویر کلیدی.

## ۱۰. نتایج پرفورمنس

| متریک | نتیجه |
|---|---|
| تصاویر | ۴۱ تصویر → ۴۶۶ فایل: JPEG بازرمزگذاری‌شده (7.5MB)، **WebP** (−۴۲٪ نسبت به jpg)، **AVIF** (−۶۵٪: 9.3MB کل، ۰.۸MB برای عرض ۴۸۰) |
| srcset | ۴ عرض (۴۸۰/۷۶۸/۱۰۸۰/۱۴۰۰) + `sizes` vw-آگاه — موبایل فقط 480 را می‌گیرد |
| LCP | `fetchPriority=high` روی hero (هوم) + تصویر اول گالری + هیرو دسته |
| Lazy | همه تصاویر غیر-اول `loading=lazy` + `decoding=async` |
| پاسخ سرور (production) | همه صفحات کلیدی **< 110ms** |
| HTML | هوم 128KB / محصول 195KB (streamed) |
| انیمیشن | فقط transform/opacity/opacity-grid — `prefers-reduced-motion` رعایت شد |

## ۱۱. نتایج دسترس‌پذیری

- ✅ skip-link به `#main` (موجود، بازتأیید)؛ `*:focus-visible` سراسری.
- ✅ آکاردئون: button + aria-expanded + aria-controls + role=region.
- ✅ Combobox جستجو: role/aria-expanded/aria-activedescendant/aria-autocomplete؛ Esc می‌بندد.
- ✅ لایت‌باکس: role=dialog + aria-modal + Esc + قفل اسکرول + بازگشت فوکوس.
- ✅ Toggleها/سوییچ‌ها با aria-checked (consent از ۱.۵.۰)؛ alt توصیفی همه تصاویر جدید.
- ⏳ باقیمانده: ممیزی کنتراست سطح AA همه صفحات + تست صفحه‌خوان واقعی (NVDA/VoiceOver).

## ۱۲. بهبودهای جزئی باقیمانده

1. **دامنه واقعی + GSC/GA4:** verify، submit sitemapها، GA4 پشت گیت consent (زیرساخت از ۱.۵.۰ آماده).
2. **ممیزی کامل WCAG 2.1 AA** با صفحه‌خوان واقعی.
3. **Lighthouse روی استقرار واقعی** (در سندباکس قابل اتکا نیست).
4. حذف تدریجی `public/images/*.jpg` اصلی پس از تثبیت (فعلاً به‌عنوان fallback نگه داشته شدند).
5. تصاویر آپلودی ادمین آینده → اتصال به pipeline `SmartImage` (الان فقط دارایی‌های opt).
6. «پیشنهاد هلسا» اکنون از محبوب‌های دسته است؛ با داده رفتاری واقعی می‌تواند شخصی شود.
