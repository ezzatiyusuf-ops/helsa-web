## ۲. روش‌شناسی و اصول اجرا

- **ادامه از کدبیس موجود** — هیچ rewrite؛ هویت بصری (Luxury Minimal Iranian، توکن‌های معنایی، RTL، Vazirmatn) دست‌نخورده.
- **اثبات با اجرا:** هر ادعا با curl واقعی، کد وضعیت HTTP، یا typecheck/lint تأیید شد — نه با ادعای کد.
- **اصل قیمت سرور-محور** در هر فیچر جدید (عمده، سینی، هدیه) بدون استثنا برقرار.
- **اصل «فرض باگ»:** گاردها با ورودی بدعنوان عمدی شکسته شدند (401/403/400/404/429) — نه فقط مسیر خوش‌بینانه.
- **بدون توقف:** هر خطا (تایپ‌خطای drizzle، OOM سندباکس، rate-limit سوزانده‌شده) علت‌یابی و رد شد، نه دور زده.

## ۵. فاز ۴ — هاردنینگ امنیتی

- `src/lib/security.ts`: `assertSameOrigin`, `clientKey`, `rateLimit` (پنجره لغزان), `genericAuthMessage` — روی همه مسیرهای حساس.
- کوکی سشن: `HttpOnly` + `SameSite=Lax` + `Secure` در production، JWT HS256 با عمر ۷ روز.
- رمز: `scryptSync` با salt تصادفی (`scrypt$salt$hex`)؛ سرویس auth **server-only**.
- هدرها: CSP سخت‌گیرانه (`unsafe-eval` فقط dev)، `X-Frame-Options`، `nosniff`، `Referrer-Policy`.
- **فیکس باگ واقعی:** `customerIdFromSession()` به `src/lib/session.ts` اضافه شد — استخراج id از `sub: "customer:{id}"` استاندارد شد و ۵ فایل مصرف‌کننده پچ شدند.

**وضعیت: کامل + اثبات‌شده در فاز ۵.**

## ۱۱. فاز ۱۱ — پرتال عمده‌فروشی B2B ⭐

**بزرگ‌ترین فیچر ۱.۵.۰.** معماری: قیمت عمده ۱۰۰٪ سرور-محور، تخفیف پلکانی، rules قابل تنظیم ادمین.

| اجزا | جزئیات |
|---|---|
| ثبت‌نام | `/wholesale/register` فرم چندمرحله‌ای + `POST /api/wholesale/register` (Zod، 409 برای تکراری) |
| ورک‌فلو | pending → ادمین از `/admin/wholesale` تأیید/رد می‌کند؛ discountPercent و rules (minSubtotal/minItemQty) قابل تنظیم |
| کاتالوگ | `GET /api/wholesale/catalog` — ۱۷۲ آیتم با قیمت عمده محاسبه‌شده سرور (نمونه: آبنبات زعفرانی ۱۴۵k → ۱۲۳k با ۱۵٪) |
| سفارش | `POST /api/wholesale/orders` — گاردهای 401 (بدون سشن) / 403 (مشتری عادی) / 400 (زیر حداقل، موجودی ناکافی) / 404 (محصول نامعتبر) — همه اثبات‌شده با curl |
| تکرار سفارش | `{ repeatOrderId }` — اقلام از سفارش قبلی سمت سرور بازخوانی و دوباره اعتبارسنجی می‌شوند |
| دیتابیس | جدول `wholesale_businesses` + کد یکتا (WSB-…) + seed دمو |

**راستی‌آزمایی end-to-end:** ورود دمو (approved، ۱۵٪) → سفارش ۴ آیتم → `WSO-VH090Q71` (۴۱,۳۲۰,۰۰۰ تومان، قیمت سرور) → تکرار → `WSO-VH0SDG88` → همه گاردهای منفی پاس.

**وضعیت: کامل و اثبات‌شده.**
