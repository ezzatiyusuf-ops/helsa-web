# اینستاگرام هلسا — راهنمای کامل

## معماری (صادقانه)

| منبع | چه می‌دهد | کش |
|------|-----------|-----|
| **LIVE** — Instagram Graph API | پست‌های واقعی + استوری‌های فعال ۲۴ ساعتهٔ @Helsa.Nuts | پست ۳۰ دقیقه، استوری ۵ دقیقه |
| **CURATED** — جدول `instagram_posts` | پست‌ها/استوری‌های منتخبی که از پنل مدیریت می‌شوند | — |

- اعتبارنامهٔ LIVE در جدول `site_settings` ذخیره می‌شود (اولویت خواندن: **پنل → env**)؛ یعنی **بدون ری‌استارت سرور** فعال/غیرفعال می‌شود.
- لایک/کامنت فقط وقتی نمایش داده می‌شود که از Graph API آمده باشد؛ برای آیتم‌های منتخب **هرگز عدد ساختگی ساخته نمی‌شود**.
- اگر توکن خراب شود یا درگاه پاسخ ندهد، سایت **صادقانه به آیتم‌های منتخب برمی‌گردد** (fallback خودکار).

## اتصال فید زنده از پنل (۵ دقیقه، بدون کدنویسی)

1. **حساب اینستاگرام باید حرفه‌ای (Creator/Professional) باشد** — در اپ اینستاگرام: تنظیمات → حساب و سوئیچ → «حساب حرفه‌ای» (می‌توانید به صفحهٔ فیسبوک وصلش کنید یا نه).
2. به [developers.facebook.com](https://developers.facebook.com) بروید → **My Apps → Create App** (نوع Business) → در بخش «Add Product»، **Instagram Graph API** را اضافه کنید.
3. **Generate Access Token** (ابزار Graph API Explorer یا «Access Token» در داشبورد اپ): توکن با دسترسی **`instagram_basic`** بردارید.
4. **User ID عددی** حساب را از همان پاسخ توکن یا از `graph.instagram.com/me` بردارید (عددی بلند مانند `17841400000000000`).
5. در سایت: **پنل ادمین → اینستاگرام** → کارت «اتصال فید زندهٔ اینستاگرام»:
   - Access Token و User ID را چسبانید → **«ذخیره و اتصال»**.
   - پیام سبز `اتصال برقرار است — @Helsa.Nuts (N پست)` یعنی موفق؛ نام حساب و تعداد پست‌های واقعی نمایش داده می‌شود.
   - دکمهٔ **«تست اتصال»** هر زمان قابل اجراست؛ **«قطع اتصال»** سایت را به حالت منتخب برمی‌گرداند.
6. پست‌ها و استوری‌های واقعی همان لحظه در صفحهٔ اصلی و `/instagram` می‌آیند (کش استوری ۵ دقیقه است؛ چند دقیقه صبر کنید یا دوباره باز کنید).

> نکته: توکن‌های تست معمولاً کوتاه‌مدت‌اند؛ اگر چند ساعت بعد اتصال قطع شد، توکن را تمدید/جدید کنید و دوباره ذخیره کنید. توکن فقط در دیتابیس خودِ سایت ذخیره می‌شود و در پنل همیشه ماسک نمایش داده می‌شود (`xxxxxx…xxxx`).

## مدیریت پست‌ها و استوری‌های منتخب

پنل ادمین → «اینستاگرام»:
- **نوع**: «پست (گرید)» یا «استوری (دایره)» — استوری‌ها در نوار دایره‌ای بالای گرید می‌آیند و با کلیک، ویوئر تمام‌صفحه باز می‌شود (پیشروی خودکار، تپ چپ/راست، Esc).
- تصویر (از `/images/opt/…` یا https)، کپشن فارسی، عنوان استوری، لینک مستقیم پست یا شناسهٔ محصول (کارت به صفحهٔ محصول لینک می‌شود)، ترتیب و فعال/غیرفعال.

## API عمومی

| مسیر | توضیح |
|------|-------|
| `GET /api/instagram/feed?limit=48` | `{ source: live\|curated, posts[] }` |
| `GET /api/instagram/stories` | `{ source, stories[] }` |

## سطوح دسترسی و امنیت

- `POST/GET /api/admin/instagram/connect` → فقط ادمین (same-origin + rate-limit 60/min + zod).
- توکن هرگز در پاسخ‌های API برنمی‌گردد؛ فقط ماسک‌شده.
