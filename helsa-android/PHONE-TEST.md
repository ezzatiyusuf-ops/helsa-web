# راهنمای تست HELSA Android روی گوشی واقعی

**فایل:** `releases/helsa-v1.0.0-phonetest.apk` (~۲۱MB) — بیلد debug مخصوص تست گوشی که به سرور تست همین workspace وصل می‌شود.

**سرور فعلی این APK:** `https://drug-knight-flag-indicator.trycloudflare.com`
(آدرس لحظه‌ای تونل — `releases/tunnel-url.txt` همیشه به‌روز است)

اگر اپ «آفلاین» شد یعنی تونل عوض شده؛ فقط بنویسید «APK تازه بساز» تا با `bash scripts/phone-apk.sh` نسخهٔ جدید ساخته شود.

## ۱) نصب
1. فایل APK را از همین workspace دانلود کنید (روی گوشی یا انتقال از کامپیوتر).
2. روی APK بزنید → اندروید دربارهٔ «نصب از منابع ناشناس» می‌پرسد → اجازه دهید (برای مرورگر فایل/Downloads).
3. نصب → باز کردن.

## ۲) چیزی که باید ببینید
- **اسپلش** کرم با لوگوی هلسا → بدون تأخیر مصنوعی
- **آنبوردینگ** فقط در اولین اجرا (۳ صفحه + «رد کردن») — دفعهٔ بعد مستقیم خانه
- **خانه:** هدر + جستجو، دسته‌ها، «برای چه مناسبتی خرید می‌کنید؟» (فوری)، پیشنهاد ویژه، دسترسی سریع
- RTL کامل فارسی، فونت وزیرمتن، پالت سبز/کرم برند

## ۳) سناریوهای تست پیشنهادی
| سناریو | انتظار |
|---|---|
| تب «محصولات» | گرید ۲ستونه از **۱۸۴ محصول واقعی**؛ چیپ دسته‌ها (۳۵ دسته)؛ مرتب‌سازی |
| جستجو «خرما» | نتایج همان موتور جستجوی سایت + تاریخچهٔ جستجو |
| لمس یک محصول | گالری اسلایدی، قیمت/تخفیف، موجودی، مشخصات، آلرژن، مرتبط‌ها |
| افزودن به سبد | بج تعداد روی تب سبد +۱ |
| تب سبد | قیمت‌ها **بعد از اعتبارسنجی سرور** (اگر قیمت عوض شده باشد نشان می‌دهد) |
| ورود (حساب من) | شمارهٔ موبایل معتبر → صفحهٔ کد: بنر زرد «حالت توسعه» **کد تست را نشان می‌دهد** — همان را وارد کنید ✓ |
| ثبت سفارش | فرم کامل + روش ارسال/پرداخت واقعی از سرور؛ چون درگاه پیکربندی نیست، هشدار صادقانهٔ «حالت آزمایشی» می‌بینید |
| سفارش‌ها (بعد از لاگین) | سفارش ثبت‌شده با کد، مبلغ و وضعیت — تاریخ شمسی |
| کمپین‌ها | فعال/به‌زودی/پایان‌یافته از تاریخ‌های واقعی |
| قطع اینترنت گوشی | پیام فارسی «اتصال اینترنت برقرار نیست» + تلاش دوباره |

## ۳.۵) اگر اپ «بدون اتصال» شد (مهم)
تونلِ تست موقتی است و آدرسش ممکن است عوض شود. **نیازی به APK جدید نیست:** در هدر صفحهٔ خانه، کنار عنوان «هلسا»، یک آیکون سرور (DNS) است — بزنید، آدرس تازه را بچسبانید، ذخیره، اپ را ببندید و دوباره باز کنید. (این قابلیت فقط در بیلد تست وجود دارد.)

## ۴) محدودیت‌های صادقانهٔ این بیلد تست
- **سرورِ پشت اپ، همین سندباکس تست است** از طریق تونل عمومی موقت (trycloudflare.com). اگر سندباکس بخوابد یا ری‌استارت شود، آدرس تونل عوض می‌شود و اپ «بدون اتصال» نشان می‌دهد — کافی است بگویید تا APK را با آدرس تازه بسازم (~۱ دقیقه).
- پیامک واقعی ارسال نمی‌شود (SMS_PROVIDER روی سرور تنظیم نیست) — کد تست صادقانه در خود اپ نمایش داده می‌شود.
- پرداخت در حالت آزمایشی است؛ سفارش ثبت می‌شود ولی پولی حرکت نمی‌کند.
- بیلد **release** (helsa-v1.0.0-release.aab) به دامنهٔ تولید `helsairanian.ir` اشاره می‌کند و بعد از deploy همان کلید تست خواهد بود.
